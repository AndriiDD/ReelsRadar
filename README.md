# ReelsRadar

«ИИ рилс-продюсер» — сервис для мониторинга рилсов конкурентов. Добавьте аккаунт из Instagram, загрузите его 20 последних рилсов со статистикой, найдите залетевшие ролики в удобной сетке и превратите их в свой сценарий: перевод на русский, разбор на Хук, Скрипт и Call to action, редактирование и сохранение ремикса.

## Что внутри

Сейчас это демо-прототип интерфейса в одном файле `index.html` (без сборки и зависимостей):

- **Конкуренты** — добавление аккаунта, список загруженных конкурентов, таблица последних 20 рилсов.
- **Главное** — сетка или список рилсов, поиск, фильтры по автору и статусу, сортировка.
- **Ремикс рилса** — блоки «Хук», «Скрипт», «Call to action» с редактированием, сохранением и сбросом к оригиналу.

Данные хранятся в браузере (`localStorage`). Рилсы при добавлении конкурента тестовые, разбор на блоки делается делением по предложениям, без нейросети.

## Запуск

Откройте `index.html` в браузере.

Бесплатный хостинг через GitHub Pages: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**. Через минуту сайт появится по адресу `https://<ваш-логин>.github.io/ReelsRadar/`.

## План перехода на боевую версию (все сервисы бесплатные)

| Задача | Сервис |
|---|---|
| Интерфейс и серверная часть | Next.js |
| База данных и вход | Supabase |
| Загрузка рилсов | Apify (бесплатный кредит) |
| Перевод и разбор на Хук / Скрипт / CTA | Gemini API (Google AI Studio) |
| Хостинг | Vercel |

Ключи храните в `.env.local` и не коммитьте их в репозиторий.

## Важно

Загрузка данных из Instagram может нарушать правила платформы. Используйте сервис для личного анализа и переписывайте сценарии под себя.
